# Valeurs locales

Les fichiers publiés utilisent des marqueurs pour éviter d'exposer des
informations propres à la machine ou à son utilisateur.

- `__HOME__` : dossier personnel de l'utilisateur, par exemple `/home/user`
- `__WEATHER_LOCATION__` : ville utilisée par le widget météo
- `__DEVICE_NAME__` : nom local d'un appareil ou d'un point d'accès

Ces marqueurs sont présents uniquement dans la copie GitHub. La configuration
active de la machine conserve ses vraies valeurs.
