# Precision Shell system snapshot

This directory is a restorable snapshot of the active local configuration:

- `quickshell/precision-shell/`
- `niri/config.kdl`
- `niri/precision-style.kdl`
- `gtklock/precision/`
- `bin/precision-lock*`

The wallpaper asset is included so the desktop and lock screen can be restored
exactly. Generated backup files and logs are intentionally excluded.
